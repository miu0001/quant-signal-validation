# Signal Discovery and Validation Under Noise

This project studies the problem of identifying and validating weak predictive signals
in noisy stochastic environments, a central challenge in quantitative research.

Using controlled simulation experiments, we analyze how apparent in-sample predictability
can deteriorate out-of-sample due to noise, sampling variability, and distributional shifts.

## Objectives
- Simulate stochastic data-generating processes with latent signals
- Evaluate model performance across varying signal-to-noise regimes
- Assess robustness using out-of-sample testing and resampling methods

## Methods
- Monte Carlo simulation
- Linear and regularized regression models
- Cross-validation and stress testing under distributional shift

## Key Takeaways
- In-sample performance alone is insufficient for reliable signal discovery
- Weak signals are highly sensitive to noise and regime changes
- Robust validation is essential for quantitative decision-making
